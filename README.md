# 奶爸机 — 超早期断奶数据采集系统

> 版本 1.0.0

---

## 后端化说明

当前应用已内置本地后端。Electron 启动时会在主进程中拉起 `backend/src/server.js`，页面通过本地 API 保存批次、每日记录、推荐日志、审批日志、执行日志和 sceneState。数据文件位于 Electron `userData/data/naibaji-db.json`。

开发验证：

```bash
npm test
npm start
```

后端设计见 `docs/后端设计.md`。

## 一、需求概述

面向 3-21 日龄超早期断奶仔猪的智能配奶数据采集系统。饲养员每日录入腹泻情况和教槽情况，系统自动生成配奶曲线，平衡生长和腹泻。采集的数据用于后期深度学习模型训练。

### 1.1 核心流程

```
批次创建（日龄+头数+母猪信息）
  → 胃容量公式自动生成基线配奶计划
  → 每日录入（腹泻+教槽+环境+死亡淘汰）
  → 控奶模式可选（渐进递减配奶次数）
  → 批次完成 → 导出训练数据 JSON
```

### 1.2 饲养员每日操作

1. 确认当日头数
2. 录入腹泻轻/中/重头数
3. 录入教槽好/中/差（或具体克数）
4. 选填：死亡淘汰、温湿度、料液比、饮水类型
5. 点击「录入并推进」→ 系统自动更新配奶曲线

## 三、每日数据记录规范

### 3.1 必填字段

| 字段 | 格式 | 说明 |
|:----|:----|:------|
| dayAge | 整数 | 日龄，如 3, 4, 5... |
| totalMilkG | 整数(g) | 当天整群实际奶粉总用量 |
| totalCreepG | 整数(g) | 当天整群实际教槽总采食量 |
| headCount | 整数 | 当天仔猪头数 |

### 3.2 腹泻记录

| 字段 | 类型 | 范围 | 说明 |
|:----|:----|:----:|:-----|
| diarrheaMild | 整数 | ≥0 | 轻度腹泻头数 |
| diarrheaModerate | 整数 | ≥0 | 中度腹泻头数 |
| diarrheaSevere | 整数 | ≥0 | 重度腹泻头数 |

**腹泻率计算：**
```
腹泻总头数 = 轻 + 中 + 重
当日腹泻率(%) = 腹泻总头数 / 当前头数 × 100
```

### 3.3 死亡淘汰（选填）

| 字段 | 类型 | 默认 | 说明 |
|:----|:----|:----:|:-----|
| death | 整数 | 0 | 当天死亡头数 |
| cull | 整数 | 0 | 当天淘汰头数 |

**更新头数规则：**
```
次日头数 = 今日头数 - 死亡 - 淘汰
```

### 3.4 环境数据（选填）

| 字段 | 类型 | 单位 | 说明 |
|:----|:----|:----:|:-----|
| minTemp | 数字 | ℃ | 当日最低温 |
| maxTemp | 数字 | ℃ | 当日最高温 |
| avgTemp | 数字 | ℃ | 当日平均温 |
| minHum | 数字 | % | 当日最低湿度 |
| maxHum | 数字 | % | 当日最高湿度 |
| avgHum | 数字 | % | 当日平均湿度 |

### 3.5 饲喂参数

| 字段 | 类型 | 默认 | 说明 |
|:----|:----|:----:|:-----|
| dilution | 数字 | 5 | 料液比（水:粉），默认 1:5 |
| waterType | 枚举 | none | 饮水类型 |
| sampleWeight | 数字 | — | 样本称重(kg/头)，可选 |

**waterType 可选值：**

| 值 | 含义 |
|:---|:-----|
| none | 未提供水盘 |
| fresh | 提供清水 |
| vital | 提供维康质 |
| sour | 提供酸溜溜 |

## 四、核心模型公式

### 4.1 胃容量（基线计划）

```
容量(g/天)  = 体重(kg) × 30(ml/kg) × 0.85(安全系数) × 12(次/天) ÷ 6(兑水1:5)
头均奶粉(g/头) = 容量 × 渐进比例
总奶粉(g) = 头均奶粉 × 头数
增重(kg)  = 奶粉量(g) / (0.9 × 1000)
```

### 4.2 渐进比例

| 进栏天数 | 比例 | 含义 |
|:--------:|:----:|:-----|
| D1（刚断奶） | 30% | 过渡适应 |
| D2 | 60% | 快速上量 |
| D3 | 78% | 接近平台 |
| D4+ | 85% | 平台维持 |

### 4.3 控奶计划（渐进递减）

控奶的核心逻辑是教槽阈值决定启动值，逐日递减至最低 2 次，日增重 180g 保护。

**启动参数：**

| 教槽 3 日均值 | 启动次数 | 递减间隔 |
|:-------------:|:--------:|:--------|
| ≥ 70g | 8 次/天 | 每 1 天减 1 次 |
| 30 ~ 70g | 10 次/天 | 每 2 天减 1 次 |
| < 30g | 11 次/天 | 每 3 天减 1 次 |

**控奶后计划公式：**

```
单次上限(g/头) = 胃容量 × 0.85 / 12
控奶后头均奶粉(g/头) = min(原计划, 单次上限 × 当前次数)
控奶后总奶粉(g) = 控奶后头均奶粉 × 头数
单次配奶量(g/批) = 控奶后总奶粉 / 当前次数
```

**日增重保护：**

```
预计日增重(g) = (控奶后总奶粉 + 最新教槽×0.7) / 0.9
if 预计日增重 < 180g → 停止递减，维持当前次数
```

**下限：** 最少 2 次/天

### 4.4 内部固定参数

| 参数 | 值 | 说明 |
|:----|:---|:-----|
| FCR | 0.9 | 料肉比，不可调 |
| 胃容量系数 | 30ml/kg | 每 kg 体重胃容量 |
| 安全系数 | 0.85 | 胃容量安全裕度 |
| 兑水比 | 1:5 | 1g 粉 + 5ml 水 |
| 基线配奶次数 | 12 次/天 | |
| 控奶下限 | 2 次/天 | |

### 4.5 断奶体重标准（参考线）

| 日龄 | 体重(kg) | 日龄 | 体重(kg) |
|:----:|:--------:|:----:|:--------:|
| 3d | ≥2.3 | 9d | ≥3.4 |
| 4d | ≥2.4 | 10d | ≥3.6 |
| 5d | ≥2.6 | 11d | ≥3.8 |
| 6d | ≥2.8 | 12d | ≥4.0 |
| 7d | ≥3.0 | 13d | ≥4.2 |
| 8d | ≥3.2 | 14d | ≥4.4 |

> 14 日龄后按最后增速 (200g/d) 外推

## 五、训练数据导出格式

### 5.1 批次元信息

```json
{
  "batch": {
    "startAge": 3,
    "endAge": 21,
    "feedingDays": 18,
    "startWeight": 2.3,
    "headCount": 20,
    "sowParity": 3,
    "litterSize": 12,
    "plannedTotalMilkG": 55040,
    "standardWeaningWeight": 4.4
  }
}
```

### 5.2 每日记录（特征）

```json
{
  "dailyRecords": [
    {
      "dayAge": 3,
      "totalMilkG": 700,
      "totalCreepG": 0,
      "perPigMilkG": 35.0,
      "perPigCreepG": 0,
      "headCount": 20,
      "diarrheaMild": 0,
      "diarrheaModerate": 0,
      "diarrheaSevere": 0,
      "dailyDiarrheaRate": 0,
      "sampleWeight": null,
      "death": 0,
      "cull": 0,
      "minTemp": null,
      "maxTemp": null,
      "avgTemp": null,
      "minHum": null,
      "maxHum": null,
      "avgHum": null,
      "dilution": 5,
      "waterType": null
    }
  ]
}
```

### 5.3 标签

```json
{
  "labels": {
    "finalDiarrheaRate": 2.5,
    "totalMilkG": 52000,
    "totalCreepG": 12000,
    "avgPerPigMilkG": 2600,
    "avgPerPigCreepG": 600,
    "pigDays": 360,
    "totalDiarrheaCases": 9
  }
}
```

**标签计算公式：**

```
最终腹泻率(%) = 总腹泻头次数 / 总猪·天数 × 100
总腹泻头次数 = Σ(每天轻+中+重腹泻头数)
总猪·天数 = Σ(每天头数)
```

### 5.4 后续训练目标

| 目标 | 说明 |
|:----|:-----|
| 预测腹泻率 | 回归模型，以 finalDiarrheaRate 为标签 |
| 预测死亡风险 | 分类模型，以 death 是否 > 0 为标签 |
| 优化 FCR | 从实际数据中学习真实料肉比 |
| 优化控奶策略 | 找到教槽阈值与最佳递减节奏 |

## 六、食欲分级标准（教槽）

| 等级 | 日均采食量参考 | 说明 |
|:----|:-------------:|:-----|
| 好 | ≥ 70g/头 | 教槽采食积极 |
| 中 | 30 ~ 70g/头 | 教槽采食一般 |
| 差 | < 30g/头 | 教槽采食不理想 |

如饲养员记录具体克数则以克数为准，三档分类为最低要求。
