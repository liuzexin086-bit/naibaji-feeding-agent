# 奶爸机超早期断奶 Agent — Staging 现场模拟清单

## 发布门槛

- [ ] staging Worker 使用独立名称，不绑定 `org.u3u4.top`。
- [ ] `AGENT_ENABLED=false` 时，原模型、Supabase 同步和现场记录均正常。
- [ ] 匿名请求、过期 JWT、跨用户 batch、旧 revision 全部被拒绝。
- [ ] 管理员创建默认 SOP 后，已启动批次的模板快照不会被新版本改变。

## 时间与教奶

- [ ] 09:00 入栏得到当日 17:00 首次教奶。
- [ ] 非标准入栏使用实际时间 +8h，展示需确认的流程偏差。
- [ ] 首次教奶后显示 10 分钟轻柔驱赶。
- [ ] 标准入栏生成 17:00、20:00、23:00、次日 02:00、05:00、08:00 自动下奶，08:00 后不再生成教奶餐。
- [ ] 首夜教奶程序不要求逐餐确认；次日 08:00 早巡栏和第三天掉队猪评估为人工步骤。

## 数量与对账

- [ ] 10/20/非整栏头数的单次下粉量均来自生产模型，并按设备精度取整。
- [ ] 设备建议和页面只显示下粉量与定时下奶点，不把水量或奶液量列为设置项。
- [ ] 教奶阶段只按已排定餐次对账，标记 `planSource=sop_teaching`。
- [ ] 正常饲喂阶段与 `feeding-model + V5-Lite` 黄金样例一致。
- [ ] 每个数字说明模型/SOP 版本、计算日期和依据。

## 掉队、饮水与异常

- [ ] 个体标记包含不到槽/腹部空瘪观察和操作人。
- [ ] 补奶 2–3 次后不再自动延长，第三天选择保留或返母猪。
- [ ] 给水关闭、上料前检查、恢复均需人工确认。
- [ ] 严重腹泻、死亡异常、持续拒奶、腹部空瘪、堵塞、探头污染进入异常模式。
- [ ] 异常模式不提供常规增量建议，不自动操作设备，不进行兽医诊断。

## 转料与维护

- [ ] 8–11日龄出现奶粉拌干料任务。
- [ ] 12–14日龄出现奶料 4:1 奶泡料任务。
- [ ] 20日龄后只有在采食、体况、粪便确认后给出每天 2–3 次过渡草案。
- [ ] 每2天清水循环/奶槽清洗，每7天深度清洗。
- [ ] 批次结束检查粉仓、出粉口、主机、奶槽、干燥和防尘。

## Agent 与审批

- [ ] 提示注入不能获得 shell、文件、任意网络或跨用户数据。
- [ ] 模型供应商不可用时显示降级信息，确定性 SOP/API 仍工作。
- [ ] 决策卡只能引用本轮确定性工具证据。
- [ ] 批准/拒绝使用当前 revision；旧 revision 返回 `NBJ_AGENT_STALE`。
