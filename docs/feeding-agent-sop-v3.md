# 奶爸机超早期断奶执行 Agent 方案（V3）

## 1. 执行边界

- 奶爸机自动完成配奶与下奶，现场只设置每次下粉量和定时下奶时间。
- `feeding-model + V5-Lite` 是数量、餐次和完整配奶曲线的唯一权威来源。
- SOP 调度器只决定首日教奶时间、人工观察、饮水、教槽、转料和清洗任务。
- Agent 解释确定性结果、组织任务和生成审批草案，不心算奶量，不直接控制设备。

## 2. 断奶第一天

1. 上午 09:00 前完成挑猪、称重和入栏，并记录实际入栏时间。
2. 适应 8–10 小时。17:00 落在该窗口内时作为首次教奶时间；否则使用“实际入栏时间 + 8 小时”并记录偏差。
3. 首次教奶后，现场完成 10 分钟轻柔驱赶。
4. 设备从首次教奶起每 3 小时定时下奶，覆盖断奶首日和首夜。
5. 标准 09:00 入栏对应设备时间为 17:00、20:00、23:00、次日 02:00、05:00、08:00。
6. 次日 08:00 下奶后进行早间巡栏，完成后结束教奶程序并进入正常模型饲喂。

## 3. 单次下粉量

- 先由生产模型计算该日整群总奶粉量和模型餐次。
- 单次下粉量取生产模型对应设备餐的粉量，并按冻结的设备最小精度取整。
- 首日只执行实际排定的教奶餐，不把模型完整日计划与首日适应期实际量直接计算为设备缺口。
- 视频脚本中的 `10 mL/头/次`、`35 g/20头/次`只保留为来源资料参考，不作为设备执行值。

每个设备点至少保存：

- 日龄和计算日期；
- 下奶时间；
- 单次下粉量；
- 当日模型总粉量与模型餐次；
- 模型版本、SOP 版本和计算依据。

## 4. 第二天以后

- 不再运行“每 3 小时教奶循环”，按生产模型的完整设备曲线执行正式饲喂。
- 不主动到槽或腹部空瘪的仔猪进入独立掉队猪流程：人工补奶 2–3 次，第三天人工评估留养或返母猪。
- 掉队猪第三天评估不是自动教奶程序的延长。

## 5. 饮水、教槽和维护

- 断奶入栏当天关闭水嘴，默认到 12 日龄开始上料时恢复；关闭与恢复均由现场人员确认记录。
- 8–11 日龄开始奶粉拌干料；12–14 日龄使用奶料 4:1 的奶泡料；20 日龄后按采食、体况和粪便状态逐步转料。
- 每两天清水循环和奶槽清洗，每七天深度循环清洗，批次结束完成整机清洁、干燥和防尘。

## 6. “完成本步”交互

- 点击后立即进入“正在保存”状态，防止重复提交。
- 原子完成接口返回任务和最新 run 后，页面立即局部更新当前步骤。
- 完整时间线在后台重新校准，不阻塞本次点击反馈。
- revision 冲突或保存失败时撤销忙碌状态，刷新权威数据并提示重新确认。
