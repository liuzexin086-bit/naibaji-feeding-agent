# 奶爸机超早期断奶执行 Agent 方案（V4）

## 数量权威

所有饲喂数量由确定性程序按以下顺序解析：

1. SOP 直接给出整段或当日总量时，执行 SOP 总量。
2. SOP 没有直接给总量，但给出的单餐量、头数、餐次等参数可以推导总量时，执行 SOP 推导量。
3. SOP 既不能直接也不能间接确定总量时，才调用 `feeding-model + V5-Lite` 计算总量。

Agent 不得混合、平均或自行选择多个来源。每个结果保存数量权威、依据、SOP 版本、模型版本和计算日期。

## 当前首夜教奶程序

- 实际入栏后适应 8–10 小时；标准 09:00 入栏在 17:00 首次下奶。
- 设备自动在 17:00、20:00、23:00、次日 02:00、05:00、08:00 下奶；08:00 早巡栏后结束教奶。
- 当前 SOP 的 `35g/20头/次` 是可执行参数。程序按有效头数和设备精度计算单餐量，再按实际排定餐数汇总程序总量。
- 例如 20 头、标准 6 餐：每餐 35g，首夜程序共 210g。
- 若未来模板直接填写首夜程序总粉量，直接总量优先；程序按餐次和设备精度分摊，最后一餐吸收舍入差。

## 正常饲喂

当前 SOP 没有直接或间接给出正常饲喂阶段的日总量，因此从次日早巡栏结束后的正常饲喂曲线继续使用 `feeding-model + V5-Lite`。设备设置仍只包含定时下奶时间和下粉量。
