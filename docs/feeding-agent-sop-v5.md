# 奶爸机现场执行规则 V5

- 计划日由批次 `current_day_index` 推进，不以系统日期或当前时刻阻断。
- 断奶首日教奶固定为 `17:00、20:00、23:00、02:00、05:00、08:00`。
- feeding-model + V5-Lite 先计算单头单餐量；整栏单次量为单头单餐量乘有效头数并向下取设备精度，程序总量为整栏单次量乘实际餐次，禁止由日总量反推单次量。
- 正常饲喂初始为每天 10 次；`00:00` 与 `12:00` 不配奶。
- 控奶继续按生产模型的教槽采食逻辑递减餐次。
- 推进日龄时冻结当日计划总粉、单次量、餐次、时间点和来源到日记录，同时保留真实提交时间用于审计。
