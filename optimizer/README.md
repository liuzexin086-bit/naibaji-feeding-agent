# 奶爸机 — 饲喂参数梯度下降优化器

基于现有模型的纯 NumPy 梯度下降优化器，**不依赖 PyTorch**。

> **EXPERIMENTAL**
> **NOT FOR PRODUCTION**
> **现有旧参数输出已失效，禁止导入设备或生产模型。**

## 架构

```
simulate.py  (入口：生成模拟数据 → 训练 → 输出)
    ├── model.py      (可微前向传播)
    ├── loss.py       (损失函数 L = -ADG + λ₁×腹泻惩罚 + λ₂×正则)
    ├── gradient.py   (数值梯度：有限差分)
    └── train.py      (梯度下降主循环)
```

## 可调参数（7个）

θ₁ D1 比例、θ₂ D2 比例、θ₃ D3 比例、θ₄ D4+ 比例、θ₅ FCR、θ₆ 教槽当量、θ₇ 日增重保护阈值

## 运行

```bash
python simulate.py
```

## 输出

- 每 5 轮打印损失、ADG、腹泻率、参数值
- 结束后打印参数收敛对比 + 最终梯度
